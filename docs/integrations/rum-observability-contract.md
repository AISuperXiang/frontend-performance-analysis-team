# RUM 与可观测数据契约

## 数据口径

- 必须记录指标定义、采集 SDK、单位、窗口、采样率、去重规则、版本和时区。
- 口径变化、SDK 升级和采样策略变化必须作为基线断点。
- 现场指标与实验室指标名称相同也不能默认口径完全一致。

## 查询与分群

- 至少按路由、版本、设备、网络、浏览器和关键用户群检查 p50、p75、p95 与样本量。
- 时间序列必须对齐发布、活动、故障和流量结构变化。
- 业务关联分析记录混杂因素和所需实验。

## 隐私与最小化

- 只使用完成性能分析所需的聚合或匿名数据。
- 不收集、输出或持久化无关用户标识、凭据和敏感内容。
- 访问生产监控前确认权限、用途和输出边界。

## 缺失处理

- 缺少样本量、版本或分群时不做现场覆盖率结论。
- 数据延迟超过分析窗口时标记 freshness 风险。
- 无现场数据时只设计后续监控计划，不估算虚假收益。
