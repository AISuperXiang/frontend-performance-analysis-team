# 浏览器性能能力调用契约

## 调用前输入

- 必须提供 URL 或本地访问方式、关键旅程、允许动作、认证状态和测量环境。
- 明确是否允许冷缓存、刷新、导航、滚动、点击和重复采样。
- 没有稳定复现步骤时先输出测量计划。

## 授权与安全

- 认证页面、生产账户、敏感数据或有副作用动作必须获得用户明确授权。
- 默认只执行只读导航和测量，不提交表单、不购买、不删除、不修改状态。
- 证据中不得保存 Cookie、Token、密码或无关用户数据。

## 输出契约

- 输出包含环境、步骤、次数、指标、原始证据引用、异常、方差和工具限制。
- trace、waterfall、timing、coverage 和截图必须关联采样轮次。
- 任何综合评分都必须附拆解指标和关键诊断证据。

## 不可用降级

- 工具不可用时读取用户提供的 trace、HAR、报告或截图并标记来源。
- 没有任何运行时证据时降级为静态分析 V1，不声称已验证真实性能。
- 列出恢复 V3 所需的最小访问、环境和采样条件。
