# Data Contracts

## 前端源码、依赖、构建配置与产物

- 时效要求：必须对应本次分析的代码版本、分支或提交；版本变化后重新核对静态发现。
- 缺失处理：缺少版本或构建上下文时，只能输出带假设的局部静态风险，不能声称覆盖生产代码。

### 必需字段

- 项目或仓库标识
- 代码版本
- 框架与渲染模式
- 构建入口与目标环境
- 依赖与锁文件状态
- 关键路由或用户旅程

### 允许用途

- 应用与构建建模
- 静态性能分析
- 源码到运行时证据映射
- 影响范围和实施交接

## 受控浏览器测量与原始性能证据

- 时效要求：必须来自当前目标版本和记录过的环境；URL、版本、浏览器或运行条件变化后失效。
- 缺失处理：浏览器证据不可用时将运行时结论降级为 V1 假设，输出测量计划和恢复条件。

### 必需字段

- URL 与用户旅程
- 代码或部署版本
- 浏览器与设备
- 网络与 CPU 条件
- 缓存与认证状态
- 采样时间与重复次数
- 指标值与单位
- 原始证据引用

### 允许用途

- 实验室性能基线
- 加载、交互、渲染和内存归因
- 版本对比
- 方案验证设计

## RUM、Web Vitals、APM 与业务现场指标

- 时效要求：必须说明查询窗口、数据延迟、采样率、SDK 或口径版本；口径或发布变化后重新建立基线。
- 缺失处理：缺少样本量、版本或关键分群时不输出真实用户覆盖率或收益结论；无数据时仅给监控计划。

### 必需字段

- 指标定义与单位
- 时间窗口与时区
- 样本量与采样率
- p50、p75 或 p95
- 路由、设备、网络、浏览器或版本分群
- 数据来源与口径版本

### 允许用途

- 现场性能基线
- 用户与版本分群
- 业务影响假设
- 灰度与上线收益复盘

## 性能目标、业务旅程与工程约束

- 时效要求：每次范围、用户、发布窗口、性能预算或架构约束变化后重新确认。
- 缺失处理：缺少旅程或目标预算时先完成 intake，不能直接选定最适合方案。

### 必需字段

- 关键用户旅程
- 目标用户与设备范围
- 当前基线与目标预算
- 可接受变更范围
- 发布与回滚约束
- 成功和停止条件

### 允许用途

- 分析范围
- 方案优先级
- 影响范围
- 落地路线图
- 实施验收

## 第三方工具摘要、Lighthouse 报告、HAR、trace 或用户提供截图

- 时效要求：必须记录生成时间、目标版本、工具版本、环境和原始文件来源。
- 缺失处理：只有截图或综合分数且无原始环境时，仅用作线索，不作为根因或收益的直接证据。

### 必需字段

- 工具或文件类型
- 目标 URL 与版本
- 采集环境
- 生成时间
- 原始文件或证据 ID
- 已知限制

### 允许用途

- 假设生成
- 证据补充
- 测量计划设计
- 受限条件下的报告复核
