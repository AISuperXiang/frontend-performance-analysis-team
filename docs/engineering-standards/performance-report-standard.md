# 性能分析报告标准

## 结论置顶

- 首屏说明当前性能判断、主要瓶颈、推荐方向、验证等级和最大风险。
- 结论使用具体旅程和指标，不使用泛化的性能差或建议优化。
- 没有浏览器实测或现场数据时在结论区直接标记。

## 现状与根因

- 现状包含版本、环境、旅程、指标基线、方差和对照。
- 根因按严重度、用户影响和置信度排序，并关联证据与代码位置。
- 替代解释、反向证据和未知项不得隐藏在附录。

## 方案与路线图

- 推荐方案必须说明为什么最适合当前上下文及未选方案理由。
- 每项方案附影响范围、预期收益、成本、风险、依赖、验证和回滚。
- 路线图区分补证、quick wins、结构性优化、灰度和现场复盘。

## 证据与限制

- 证据索引记录来源、时间、环境、版本和限制。
- 结论附置信度、验证等级、未覆盖范围和失效条件。
- 未执行的浏览器、构建或现场验证必须明确写出。
