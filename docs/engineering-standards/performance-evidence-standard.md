# 性能证据标准

## 证据分级

- 区分用户输入、源码事实、构建事实、浏览器原始数据、现场数据、工具摘要、推断和人工确认。
- 综合分数和自动建议只作为辅助，不作为最高级直接证据。
- 关键结论由最弱关键证据限制验证等级。

## 可追踪性

- 每个证据记录 ID、来源、版本、环境、采集时间、支持或反驳的结论、限制和失效时间。
- 报告、根因图谱、方案和风险必须引用证据 ID。
- 截图和摘要必须能追踪到原始 trace、日志、数据查询或代码位置。

## 可比较性

- 版本对比必须说明代码、配置、数据、设备、网络、缓存和浏览器是否一致。
- 不可比项必须单独列出，不能用统计处理掩盖环境差异。
- 现场指标口径变化时重新建立基线。

## 失败处理

- 证据缺失时降低结论并列最小补证动作。
- 证据冲突时保留双方、替代解释和裁决实验。
- 无法重复测量时不得输出已验证根因或收益。
