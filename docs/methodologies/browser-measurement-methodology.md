# 浏览器性能测量方法论

## 环境控制

- 记录 URL、构建版本、浏览器版本、视口、设备、网络、CPU、缓存、认证和数据状态。
- 对冷缓存、暖缓存、首访和回访分别建模，不在同一统计中混用。
- 自动化工具、扩展和调试面板可能引入开销，必须记录测量方式和偏差。

## 采样协议

- 先预热环境，再按固定步骤重复关键旅程；standard 默认至少三次，assurance 根据方差增加样本。
- 使用中位数、p75 或明确的分位数，并保留异常值说明，不只报告最好一次。
- 好坏版本对比必须使用尽量一致的设备、网络、数据和浏览器条件。

## 证据采集

- 加载场景优先采集 Navigation Timing、Resource Timing、LCP 元素、网络瀑布、优先级和 trace。
- 交互场景优先采集 Event Timing、Long Tasks/LoAF、主线程火焰图、帧和渲染流水线。
- 必要时补充 coverage、memory、User Timing 和截图，所有摘要必须关联原始证据 ID。

## 重现性与降级

- 复现步骤、环境和采样命令必须能被另一执行者重复。
- 认证、网络或工具阻断时，不得伪造运行时结论；输出测量计划并降级到 V1。
- 方差超过约定范围时先定位环境噪声、数据变化和异步竞争，再决定是否增加采样。
