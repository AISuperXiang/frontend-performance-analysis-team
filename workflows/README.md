# Workflows

本目录维护 Frontend Performance Analysis Team 的标准工作流。

| 工作流 | 文件 | 执行模式 | 默认产出 |
| --- | --- | --- | --- |
| 性能场景受理与测量设计 | `performance-intake.md` | sequential | performance-brief, measurement-plan, workflow-status |
| 前端性能完整评估 | `full-performance-assessment.md` | hybrid | performance-metrics-baseline, static-analysis-findings, runtime-profile-findings, root-cause-map, impact-scope-matrix, optimization-solution, rollout-roadmap, implementation-handoff, performance-analysis-report |
| 性能回退诊断 | `performance-regression-diagnosis.md` | hybrid | performance-metrics-baseline, runtime-profile-findings, static-analysis-findings, root-cause-map, performance-analysis-report |
| 性能优化方案与落地节奏设计 | `performance-solution-design.md` | hybrid | root-cause-map, impact-scope-matrix, optimization-solution, rollout-roadmap, implementation-handoff |
| 性能分析复核与实施交接 | `performance-analysis-delivery.md` | sequential | performance-analysis-report, impact-scope-matrix, rollout-roadmap, implementation-handoff, delivery-summary |
