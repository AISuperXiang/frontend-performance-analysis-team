# 浏览器与指标测量计划

## 场景与步骤

- 写明 URL、起点状态、操作序列、结束条件和预期页面状态。
- 为加载、交互、滚动或长会话场景分别定义步骤。

## 环境矩阵

- 记录浏览器、视口、设备、网络、CPU、缓存、认证、数据和版本。
- 说明冷暖缓存、移动桌面或好坏版本的组合优先级。

## 指标与证据

- 列出核心体验指标、诊断指标、单位、采集 API 和原始证据类型。
- 说明 trace、waterfall、timing、coverage、memory 或截图的采集轮次。

## 采样与统计

- 定义预热、重复次数、中位数或分位数、异常值和方差容忍。
- 对照实验明确保持一致和无法保持一致的条件。

## 停止与降级条件

- 认证、副作用、环境不稳定或工具不可用时停止并记录。
- 无法浏览器实测时降级为静态 V1，并列出恢复条件。
