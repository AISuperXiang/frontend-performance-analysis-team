# 浏览器运行时性能发现

## 测量环境与步骤

- 记录 URL、版本、浏览器、设备、网络、CPU、缓存、认证、次数和操作步骤。
- 关联每轮采样与原始证据 ID。

## 加载与网络

- 列 TTFB、关键请求链、LCP 分解、资源优先级、缓存、图片、字体和第三方发现。
- 每项发现关联 waterfall 或 timing 证据。

## 主线程与交互

- 列 Long Tasks/LoAF、Event Timing、脚本任务、事件和 INP 分解。
- 关联 trace 时间段、调用位置和用户动作。

## 渲染与内存

- 列 style、layout、paint、composite、帧、DOM、Hydration 和内存趋势。
- 区分瞬时峰值、持续增长和长会话退化。

## 方差与限制

- 报告中位数、范围、异常值、环境噪声和工具偏差。
- 标记无法复现、无法访问或 API 不支持的部分。
